# 🏢 Termiz IT CenterBot

🛠The following technologies were used in this project: Python (Aiogram)

📝 Brief information:
🏬 Termez IT-Center 📚You can register for courses✍ and 📒Get information about the course📇 and other additional 🗞Functions are also available✅

## Setup

- run `git clone https://github.com/kenjayevdev/Termiz_ITcenterBot.git` copy repositories
- run `cd Termiz_ITcenterBot` accessing repositories
- run `python -m venv env` to create virtual environment
- run `env\Scripts\activate` to activate the env
- run `pip install -r requirements.txt` to install all required packages
- Create a .env file and set ADMINS=#Telegram user ID and BOT_TOKEN=#BOT API KEY.
- run `python app.py`
